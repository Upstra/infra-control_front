## Project

**Upstra** — Vue 3 + TypeScript + Vite frontend for the Infra Control platform. Manages servers, VMs, rooms, users, and UPS events. Communicates with the NestJS backend via REST (axios) and WebSocket (socket.io-client).

## Commands

```bash
pnpm install        # install dependencies
pnpm dev            # dev server on port 5173 (HMR)
pnpm build          # type-check + production bundle → dist/
pnpm preview        # preview production build locally

pnpm test           # run unit tests (vitest, jsdom)
pnpm test:cov       # coverage report (lcov + text)

pnpm lint           # ESLint fix on src/**/*.{ts,vue}
pnpm format         # Prettier on src/**
```

## Architecture

### Feature-First Structure

Each domain lives under `src/features/<domain>/` with a consistent internal layout:

```
src/features/<domain>/
├── api/            # axios calls to the backend (one file per resource)
├── components/     # domain-specific Vue components
├── composables/    # Vue composables (useXxx pattern)
├── views/          # routed page components
├── store.ts        # Pinia store for this domain
├── types/          # TypeScript types/interfaces
└── exceptions/     # domain-specific error classes
```

Active features: `auth`, `users`, `roles`, `groups`, `rooms`, `servers`, `vms`, `ilos`, `vmware`, `ups`, `dashboard`, `presence`, `profile`, `settings`, `admin`, `history`, `changelog`, `logs`, `migration`, `setup`.

### Global Shared Layer

| Path | Purpose |
|---|---|
| `src/services/api.ts` | Axios singleton with JWT interceptor (auto-attaches Bearer token) and 401 → refresh token logic |
| `src/services/powerStateManager.ts` | Centralized VM/server power state management |
| `src/router/index.ts` | Vue Router — route guards check `requiresAuth` (JWT) and `requiresTempToken` (2FA flow) |
| `src/store/` | Global Pinia stores: `theme.ts`, `locale.ts`, `index.ts` (app-level state) |
| `src/stores/commandPalette.ts` | Command palette state |
| `src/components/` | Reusable UI components shared across features |
| `src/composables/` | Global composables |
| `src/layouts/` | Page layout wrappers (`default`, `none`) — set per-route via `meta.layout` |
| `src/locales/` | i18n translation files (vue-i18n) |
| `src/utils/` | Shared utilities |
| `src/shared/` | Shared helpers (e.g. `utils/http` for axios error extraction) |

### Authentication Flow

1. `auth/store.ts` manages `token` (localStorage), `tempToken` (2FA intermediate), and `currentUser`
2. `auth/token.ts` handles token persistence and cross-tab sync via `onTokenChange`
3. Router guards redirect to `/login` if `requiresAuth` and no token; redirect to `/mfa-challenge` if `requiresTempToken`
4. `api.ts` interceptor retries once on 401 using `POST /auth/refresh` (httpOnly cookie), then clears token and redirects to login on failure

### VMware / Real-Time Features

- **VM discovery** and **live migration** use Socket.io connections managed in composables under `src/features/vmware/`
- **Presence** (`src/features/presence/`) tracks connected users in real time via a shared Socket.io composable `usePresenceSocket`
- The dashboard (`src/features/dashboard/`) is modular — widgets are user-configurable and rendered via `@vue-flow/core` for topology views

### Path Alias

`@/` maps to `src/` (configured in both `vite.config.ts` and `tsconfig.app.json`).

### UI Stack

- **Element Plus** — primary UI component library (auto-imported via `unplugin-vue-components`)
- **Tailwind CSS** — utility classes
- **Headless UI** — accessible primitives
- **Heroicons + Lucide** — icon sets
- **xterm.js** — in-browser SSH terminal (`src/features/ssh/` or `logs/`)
- **Vue Flow** — node graph for infra topology / migration views
- **Chart.js via vue-chartjs** — metrics charts

### Build

Vite splits vendor chunks manually (`vendor-vue`, `vendor-ui`, `vendor-flow`, `vendor-chart`, `vendor-terminal`, `vendor-realtime`, etc.) to optimize loading. Gzip compression is applied at build time.

### Production Deployment

Served via Nginx (see `nginx.conf`) or PM2 (`ecosystem.config.cjs`). Use `pnpm start:pm2` to launch with PM2. The backend URL is configured via `VITE_API_URL` env variable (defaults to `http://localhost:3000`).

### Auto-generated Files

`src/auto-imports.d.ts` and `src/components.d.ts` are generated by Vite plugins — do not edit manually, they are gitignored.
